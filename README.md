# Overlayed

Set of example projects for Overlayed

## Documentation

For full documentation, visit [docs.overlayed.gg](https://docs.overlayed.gg).

## Examples

Check out our examples to get started:

- [TypeScript Vue Example](./examples/ts-vue-example/README.md)

## Using an example as a template

Each example is a standalone project, so you can copy its folder on its own without cloning this repo:

```bash
npx giget@latest gh:overlayed-gg/examples/examples/ts-vue-example my-app
```

Then follow the README inside the copied folder.
